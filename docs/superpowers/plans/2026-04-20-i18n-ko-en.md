# 한국어/영어 이중 언어 지원 구현 계획

> **에이전트 실행 시 필수 서브스킬:** `superpowers:subagent-driven-development` (권장) 또는 `superpowers:executing-plans` 으로 이 계획을 태스크 단위 실행. 각 단계는 `- [ ]` 체크박스로 진행 추적.

**목표:** 기존 한국어 포트폴리오 사이트에 영문판(`/en`)을 추가하고, `/` 는 한국어 기본 locale 로 URL 변경 없이 유지.

**아키텍처:** `next-intl` + App Router `[locale]` 세그먼트 + `as-needed` locale prefix. 구조적 짧은 문구는 `messages/{ko,en}.json` 사전에, 8개 케이스 스터디 장문 본문은 locale 별 JSX 파일 쌍 (`content.ko.tsx` / `content.en.tsx`) 으로 분리.

**기술 스택:** Next.js 16.0.8, React 19, TypeScript, Tailwind 4, `next-intl` (신규 추가)

**스펙 참조:** [docs/superpowers/specs/2026-04-17-i18n-ko-en-design.md](../specs/2026-04-17-i18n-ko-en-design.md)

**브랜치:** `feat/i18n-en` (이미 `main` 에서 분기 완료)

**주의:** Next.js 16에서 `middleware.ts` 는 `proxy.ts` 로 이름이 변경됨. 이 계획 전반에서 `proxy.ts` 를 사용.

- [ ] **Step 4: 요청 설정 생성** — `i18n/request.ts`

```ts
import { hasLocale } from 'next-intl';
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)
    ? requested
    : routing.defaultLocale;

  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});
```

- [ ] **Step 9: `[locale]/layout.tsx` 에 locale 검증 + Provider 추가**

이동된 `app/[locale]/layout.tsx` 를 읽고 아래 패턴으로 수정:

```tsx
import { NextIntlClientProvider, hasLocale } from 'next-intl';
import { notFound } from 'next/navigation';
import { routing } from '@/i18n/routing';
// ... 기존 import 유지 (globals.css, Metadata, fonts 등)

export default async function LocaleLayout({
  children,
  params,
}: {
  children: React.ReactNode;
  params: Promise<{ locale: string }>;
}) {
  const { locale } = await params;
  if (!hasLocale(routing.locales, locale)) {
    notFound();
  }

  return (
    <html lang={locale}>
      <body className={/* 기존 클래스 유지 */}>
        <NextIntlClientProvider>{children}</NextIntlClientProvider>
      </body>
    </html>
  );
}

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }));
}
```

기존 layout.tsx 에 있던 `metadata` export, 폰트 설정, body 클래스 등은 그대로 보존.

```tsx
const sections = [
```

```tsx
<h1 className="...">
  {tHero('greeting')}
  <br />
  <span className="...">{tHero('roleHighlight')}</span>{' '}
  {tHero('roleSuffix')}
```

```tsx
'use client';

import { useLocale } from 'next-intl';
import { usePathname } from '@/i18n/navigation';
import { Link } from '@/i18n/navigation';

const LOCALES = [
  { code: 'ko', label: 'KO', aria: '한국어로 보기' },
  { code: 'en', label: 'EN', aria: 'View in English' },
] as const;

export default function LanguageToggle() {
  const currentLocale = useLocale();
  const pathname = usePathname();

  return (
    <div className="flex items-center gap-3">
      <span aria-hidden className="text-[var(--color-border)]">│</span>
      {LOCALES.map((loc) => {
        const isActive = loc.code === currentLocale;
        return (
          <Link
            key={loc.code}
            href={pathname}
            locale={loc.code}
            aria-label={loc.aria}
            aria-current={isActive ? 'true' : undefined}
            hrefLang={loc.code}
            className={`relative py-1 spring text-sm font-semibold ${
              isActive
                ? 'text-[var(--color-accent)]'
                : 'text-[var(--color-text-muted)] hover:text-[var(--color-primary)]'
            }`}
          >
            {loc.label}
          </Link>
        );
      })}
    </div>
  );
}
```

- [ ] **Step 7: `app/sitemap.ts` 를 양쪽 locale + alternates 로 재작성**

기존 `sitemap.ts` 를 확인 후 아래 구조로 교체:

```ts
import type { MetadataRoute } from 'next';

const HOST = 'https://thmm.kr';

const PATHS = [
  '/',
  '/portfolio',
  '/portfolio/cicd',
  '/portfolio/grandbaie',
  '/portfolio/log-viewer',
  '/portfolio/ohmybaby',
  '/portfolio/redis-session',
  '/portfolio/sso-provider',
  '/portfolio/techtrade-migration',
  '/portfolio/tls-upgrade',
];

export default function sitemap(): MetadataRoute.Sitemap {
  const now = new Date();
  return PATHS.flatMap((path) => {
    const koUrl = `${HOST}${path}`;
    const enUrl = `${HOST}/en${path === '/' ? '' : path}`;
    const alternates = {
      languages: {
        ko: koUrl,
        en: enUrl,
      },
    };
    return [
      { url: koUrl, lastModified: now, alternates },
      { url: enUrl, lastModified: now, alternates },
    ];
  });
}
```
